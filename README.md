# Index9 Homebrew tap

    brew install --cask johnwils/tap/windrose

Windrose: fan control for Apple Silicon Macs (macOS 13.3+). https://index9.dev/windrose

Windrose updates itself through Sparkle. To remove it fully, open Windrose and use ⋯ → Uninstall Fan Service…, then `brew uninstall --zap windrose`.
